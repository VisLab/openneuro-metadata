
The BUCNI EnvSounds 1back is a dataset collected using the EnvSounds dataset as stimuli: envisounds.org

Participants were instructed to press a button with their right index finger when a sound from the same category was heard twice in a row.

Three participants performed 8 sessions of 7 runs, totalling approximately 4.7 hours of 1-back task performed using 10 sound categories.

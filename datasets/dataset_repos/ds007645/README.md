## Dataset Overview
This dataset contains task-based functional MRI data collected from 22 Mandarin-speaking participants (mean age = 22.09 years, SD = 2.83; 9 females) with no comprehension of Korean. Participants listened to 30 Korean popular ballads across three conditions manipulating acoustic input type and linguistic semantic access: Music-only (musical soundtrack, no lyrical access), Music-Subtitles (musical soundtrack with Chinese subtitle translations), and Recitation-Subtitles (gender-matched Korean recitation with Chinese subtitle translations). The study examined route-dependent neural reorganization during cross-linguistic song listening. Stimuli comprised 60-second excerpts from Korean ballads published between 1999–2012. The dataset is associated with the publication: Chien, L.-Y., & Tsai, C.-G. (in preparation). Lyrical and Musical Meaning in Songs: fMRI Evidence for Route-Dependent Neural Reorganization across Varying Semantic Access Conditions.

## Data Structure
Data are organized in BIDS format. Each participant folder contains anatomical (anat/) and functional (func/) subdirectories. The anat/ directory contains a T1-weighted MPRAGE image. The func/ directory contains BOLD EPI images for each of the three experimental runs, with corresponding task event files (.tsv) specifying trial onsets, durations, and condition labels (Music-only, Music-Subtitles, Recitation-Subtitles). Each run comprised 10 trials pseudo-randomized across the three conditions, for a total of 30 trials per participant.

## Acquisition Details
Neuroimaging data were acquired on a 3T Siemens MAGNETOM Prisma scanner with a 20-channel head coil at the Imaging Center for Integrated Body, Mind, and Culture Research, National Taiwan University.
Functional imaging: Gradient echo EPI; TR = 2500 ms; TE = 30 ms; flip angle = 90°; FOV = 192 × 192 mm²; matrix = 78 × 78; 45 axial slices; voxel size = 2.46 × 2.46 × 2.5 mm³; interleaved acquisition; no gap; GRAPPA acceleration factor = 2 with 24 reference lines; fat saturation.
Structural imaging: T1-weighted MPRAGE; TR/TE/TI = 2000/2.3/900 ms; flip angle = 8°; FOV = 240 × 240 mm²; 192 slices; voxel size = 0.94 mm isotropic; GRAPPA factor = 2.

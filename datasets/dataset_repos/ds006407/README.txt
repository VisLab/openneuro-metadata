This dataset includes raw T2-weighted structural MRI images and functional images acquired using the GRE-EPI sequence. All data were collected using a Bruker 7T small animal MRI scanner equipped with a cryogenic coil. In each EPI scan, mice received a 10-second optogenetic stimulation at 40 Hz starting at the 121st second (3rd minute). Please cite the article “Brain-wide spatiotemporally distinct traveling waves drive anxiety-like behaviors in mice” when using this dataset.
